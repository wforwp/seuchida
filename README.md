# 스치다

차창 밖 풍경을 짧은 음성 이야기로 소개하는 가족 여행 앱 프로토타입입니다.

## APK 실행

- APK: `apk/윤준희_스치다_release.apk`
- Android 9(API 28) 이상에서 설치할 수 있습니다. APK를 내려받은 뒤 기기 또는 에뮬레이터에 설치하세요.
- 화면은 가로 모드입니다. 한국어 음성은 기기에 설치된 TTS 엔진을 사용하므로 한국어 음성 데이터와 미디어 음량을 확인하세요.
- 주행 시작 후 60 km/h 기준 약 13초 뒤 첫 안내가 시작됩니다. 이야기 메뉴에서 미리 듣기도 가능합니다.

## 시연 범위

2.4km 가상 노선의 속도와 방향을 바꾸며 안내를 시험합니다. GPS, Pleos SDK, 차량 속도, 내비게이션과 마이크는 아직 연결하지 않았습니다. 장소와 안내 구간은 검증 전인 시연 데이터입니다. 주행 화면의 월악산·충주호 사진은 예시 이미지입니다.

## 테스트 및 빌드 환경

일반 Android Studio 에뮬레이터 Android 15(API 35), 가로 1280 × 720 화면에서 디버그 빌드 화면을 확인했습니다. 릴리스 APK는 별도 Android 15 에뮬레이터에 설치하고 앱 실행까지 확인했습니다. 기기별 음성 출력과 Pleos 차량 환경은 검증 전입니다. Pleos Connect 전용 에뮬레이터는 아직 사용하지 않았습니다.

`seuchida-source.zip`을 풀고 Android Studio에서 그 안의 `source/`를 열고 Android SDK를 설정한 뒤 Gradle 동기화 및 빌드합니다. compileSdk 36, minSdk 28, Kotlin 2.1.20, Gradle 8.14.3을 사용합니다. 소스와 리소스 라이선스는 `source/app/src/main/assets/licenses/`에서 확인할 수 있습니다.
